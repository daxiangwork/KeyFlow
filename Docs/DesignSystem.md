# KeyFlow UI 设计规范

## 设计原则

KeyFlow 是长期驻留的 macOS 鼠标效率工具。界面以浅灰白、大留白、细分割线和黑色主操作建立清晰层级。打开应用先进入首页，Smart Actions 与设置从首页进入。产品范围不包含账号、云同步、商店、AI、DPI、回报率、板载宏、按应用规则或手势。

## 色彩令牌

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| Canvas / Sidebar | `#FAFAFA` | 页面与侧栏背景 |
| Surface | `#FFFFFF` | 卡片与表单 |
| Text Primary | `#1A1A1A` | 标题、正文、主按钮、开启的开关 |
| Text Secondary | `#6B6B6B` | 辅助说明 |
| Border | `#E6E6E6` | 分割线、卡片与输入边界 |
| Hover | `#F0F0F0` | 图标、按钮和分段控件悬停 |
| Success | `#1C9C85` | 已连接、已授权、执行成功 |
| Warning | `#A8611B` | 低电量、权限或配置警告 |
| Error | `#B84242` | 错误与破坏性操作 |

不使用蓝色品牌按钮、渐变或环境光。玻璃效果不再作为页面组件的主要语言。

## 字体与间距

使用 macOS 系统字体。问候语 36pt Bold；页面标题 28pt Bold/Semibold；区域标题 18pt Semibold；正文 14pt；按钮 13pt；辅助文字 12pt。采用 8pt 基础网格，允许 4pt 文字内部节奏。卡片圆角 12px，按钮 10px，输入区域 8px。

## 页面结构

### 首页

左上角按时间显示早上好、下午好或晚上好。右上角只有 Smart Actions 与设置两个 44×44 图标按钮，悬停显示浅灰底与黑色提示条。中央使用定稿 JZ M5 PNG，保留图片自身的轮廓阴影。已连接时显示状态与真实电量；未连接时使用灰色图片并隐藏电量。权限卡片只在已连接时出现。总开关在权限缺失时关闭且不可用。

### Smart Actions

顶部为设备、权限、最近信号和全局开关。左侧为返回首页、新建按钮和规则列表；右侧为规则名称、自动保存、启停、测试、可视化触发和动作序列。鼠标按键和触发方式使用分段控件。动作执行与错误在当前步骤就地反馈，页脚保留结果与删除入口。

### 设置

仅包含输入监控、辅助功能、Smart Actions 总开关、导入配置和导出备份。

## 状态与安全

空状态提供创建入口；执行状态就地显示；错误说明原因与解决路径；规则自动保存且支持导入导出；删除和覆盖导入需要确认。权限、连接和启用状态同时使用文字与图标，不能只靠颜色。低电量不高于 20% 时使用警告色，读不到电量显示 `--`，不显示猜测值。菜单栏遵循同样的连接和电量规则。

## 品牌资源

只使用定稿资源中的黑白 AppIcon、LogoMark、KeyFlowLogo 和 Smart Actions 图标。应用图标为透明圆角外的深色方底白色标记，不额外添加阴影，不重绘 Logo，不使用旧青绿玻璃图标。
