# KeyFlow 使用说明

## 1. 安装与启动

1. 解压下载的应用包。
2. 建议将 `KeyFlow.app` 拖入“应用程序”文件夹。
3. 使用 JZ M5 的 2.4G 接收器，并确认鼠标已开机。
4. 打开 KeyFlow，首页应显示鼠标图片和“已连接”。

KeyFlow 是菜单栏工具。关闭主窗口不会退出应用，可从菜单栏的鼠标图标重新打开。

## 2. 首次授权

KeyFlow 需要两项 macOS 权限：

- **输入监控**：读取 JZ M5 的按键输入。
- **辅助功能**：执行快捷键、输入文本和其他自动化动作。

在首页或设置页点击对应“去授权”，在系统设置中允许 KeyFlow。若系统要求退出并重新打开，请退出应用后重新启动。

授权完成后，打开“启用 Smart Actions”。首页、设置页和 Smart Actions 页的总开关是同一个开关。

## 3. 创建 Smart Action

1. 在首页点击 Smart Actions 图标。
2. 点击“新建 Smart Action”。
3. 输入规则名称。
4. 选择鼠标按键：中键、前进侧键或后退侧键。
5. 选择触发方式：单击、双击或长按。
6. 点击“添加动作”，选择一种动作。
7. 填写动作参数。
8. 点击“运行测试”验证。

同一按键和触发方式只能对应一条启用规则。发生冲突时，请修改触发方式或停用另一条规则。

## 4. 动作类型

| 动作 | 参数 |
| --- | --- |
| 键盘快捷键 | 点击录制并按下组合键，Esc 取消录制 |
| 打开应用或文件 | 选择应用、文件或文件夹路径 |
| 打开网址 | 输入 http:// 或 https:// 地址 |
| 输入文本 | 输入需要自动填写的文本 |
| 运行快捷指令 | 输入 macOS 快捷指令的完整名称 |
| 执行 AppleScript | 输入 AppleScript 代码 |
| 等待 | 设置毫秒数，用于多步动作之间等待 |
| 打开 Actions Ring | 执行后在当前光标附近打开 Ring |

一条规则可以包含多个动作。使用上移、下移调整顺序，执行时会依次运行。

## 5. 使用 Actions Ring

### 创建打开 Ring 的规则

1. 在 Smart Actions 中新建或选择一条规则。
2. 选择希望使用的鼠标按键和触发方式。
3. 添加“打开 Actions Ring”动作。
4. 保持该规则启用。

例如：将“中键 · 长按”规则设置为“打开 Actions Ring”。中键长按不再是系统默认占用方式，你可以自由选择其他按键。

### 配置操作位

在首页点击 Actions Ring 图标：

- 尚未自定义时，当前已启用规则会按列表顺序自动加入，最多 8 条。
- 从右侧搜索并点击规则，或将规则拖入预览。
- 点击操作位后，可更换、移除或跳转到 Smart Actions 编辑原规则。
- 拖动操作位调整顺序。
- 支持撤销与重做。
- 已停用规则不能添加；已在 Ring 中的规则不能重复添加。
- 满 8 个后，请先移除再添加。
- 已停用或已删除的引用会自动从 Ring 中移除。

### 浮层操作

- 点击操作位：关闭浮层并执行一次规则。
- 点击中心叉号：关闭且不执行。
- 点击外部或透明空隙：关闭且不执行，点击可继续传给原应用。
- 按 Esc：关闭且不执行。
- 浮层打开后不会持续跟随光标；靠近屏幕边缘时会整块平移，避免内容被裁切。

如果没有可用规则，或尚未配置“打开 Actions Ring”动作，请按页面提示先完成设置。

## 6. 电量

- 首页在“已连接”旁显示电量，菜单栏同步显示。
- 未读到电量时显示 `--`，不会编造数值。
- 电量不高于 20% 时显示警告色。
- 未连接时不显示电量。
- 启动时读取，之后每 60 秒刷新。
- 读取失败时保留上一次有效值。

电量读取使用 2.4G 接收器的私有 HID 报告。请关闭京造网页驱动页面，避免浏览器占用配置接口。

## 7. 配置、备份与恢复

配置保存在：

```text
~/Library/Application Support/KeyFlow/
```

- `rules.json`：Smart Actions 规则。
- `actions-ring.json`：Ring 操作位的规则 UUID 顺序。

设置页和 Smart Actions 页均支持导入、导出。建议重要修改前先导出备份。配置修改会自动进行原子写入；保存失败时，请按页面提示导出备份并重试。

## 8. 暂停与退出

- 暂停：关闭“启用 Smart Actions”，鼠标恢复原始行为。
- 退出：从菜单栏选择“退出 KeyFlow”。
- 设备断连：已打开的 Ring 会关闭，规则配置保留。

## 9. 常见问题

### 按键没有触发规则

检查设备是否已连接、两项权限是否已授权、总开关是否开启、规则是否启用，以及触发按键和方式是否一致。

### 侧键原来设置的复制/粘贴仍然执行

请确认已安装最新构建。KeyFlow 只拦截刚刚由 JZ M5 产生的匹配事件，普通键盘的复制和粘贴不应受到影响。

### 电量显示 `--`

先确认鼠标使用 2.4G 接收器，再关闭京造网页驱动，等待下一次自动刷新。仍无结果时可重启 KeyFlow。

### 重新构建后反复要求授权

使用稳定的本地签名身份。可通过 `CODE_SIGN_IDENTITY` 环境变量指定本机证书；不要反复重置应用权限。

## 10. 当前不支持的硬件设置

DPI、回报率、板载宏、固件更新等仍使用京造网页驱动。KeyFlow 当前不修改这些硬件配置。
